# raccoontech-us-website

Static site for RaccoonTech US, `us.raccoontechcorp.com`.

RaccoonTech US (라쿤테크 미국 법인) is the US subsidiary of RaccoonTech. Employee groupware is at `groupware.us.raccoontechcorp.com`.

Based on the Start Bootstrap Small Business template (MIT).

```bash
npm install
npm start
```
